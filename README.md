# 著作権ドリル

日本の著作権法をゲーム感覚で学べるクイズアプリです。ビジネス著作権検定（初級）の公開されている出題範囲を参考に問題を作っています。ブラウザだけで動き、インストールは不要です。

## 内容

- 全146問（選択式・○×問題）を10分野に収録
  - 基礎知識／著作物／著作者／著作者人格権／著作権（支分権）／著作権の制限／保護期間・譲渡・登録／著作隣接権／侵害と救済／周辺の権利と実務
- **分野別レッスン**：1回10問。回答ごとに根拠条文と解説を表示
- **模擬試験**：本番と同じ全30問・60分・正答率65%以上で合格。各分野から3問ずつ出題し、最後に合否と分野別の正答数、間違えた問題の解説を表示
- 苦手な問題の自動記録と復習、XP、連続学習日数、コンボ
- キーボード操作：`1`〜`4` で選択、`Enter` でチェック／つづける

記録はブラウザの localStorage に保存されます。

## 問題の追加

`index.html` 内の `Q` 配列に、次のどちらかの形で追加します。

```js
// 選択問題：分野, 問題文, 選択肢, 正解の番号(0始まり), 根拠, 解説
M("sei","問題文",["選択肢1","選択肢2","選択肢3","選択肢4"],0,"第32条","解説"),
// ○×問題：分野, 問題文, 正しければ true, 根拠, 解説
T("sei","問題文",true,"第32条","解説"),
```

分野のキーは `kiso` `mono` `sha` `jin` `shi` `sei` `ki` `rin` `shin` `jitsu` です。問題の識別番号は分野内の並び順から自動で付くので、既存の問題の途中に挿入すると苦手問題の記録がずれます。新しい問題は各分野の末尾に追加してください。

## 注意

公式の問題ではなく、出題範囲を参考にしたオリジナル問題です。内容は2026年10月時点の日本の著作権法にもとづく学習用の要約で、細かな要件や例外を省略している箇所があります。実際の判断が必要な場面では、条文・文化庁の資料や専門家に確認してください。
