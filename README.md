# 著作権ドリル

日本の著作権法をゲーム感覚で学べるクイズアプリです。ビジネス著作権検定（初級）の公開されている出題範囲を参考に問題を作っています。React と Vite で作っています。

## 内容

- 全150問（選択式・○×問題）を10分野に収録
  - 基礎知識／著作物／著作者／著作者人格権／著作権（支分権）／著作権の制限／保護期間・譲渡・登録／著作隣接権／侵害と救済／周辺の権利と実務
- **分野別レッスン**：1回10問。回答ごとに根拠条文と解説を表示
- **模擬試験**：全30問・60分・正答率65%以上で合格。各分野から3問ずつ出題し、最後に合否と分野別の正答数、間違えた問題の解説を表示
- 苦手な問題の自動記録と復習、XP、連続学習日数、コンボ
- オフライン対応（ホーム画面に追加できるPWA）
- キーボード操作：`1`〜`4` で選択、`Enter` でチェック／つづける

記録はブラウザの localStorage に保存されます。

## どこを直せば何が変わるか

| 直したいもの | ファイル |
|---|---|
| 問題の追加・修正 | `src/data/questions.js` |
| 分野の名前・色・説明 | `src/data/categories.js` |
| マスコットのセリフ、結果画面のメッセージ、問題数・制限時間・合格ライン | `src/config.js` |
| ホーム画面 | `src/components/Home.jsx` |
| 問題を解く画面 | `src/components/Quiz.jsx` |
| 結果画面 | `src/components/Result.jsx` |
| マスコットの絵 | `src/components/Mascot.jsx` |
| 色・デザイン | `src/styles.css`（色は先頭の `:root` の変数） |
| 画面の切り替え、成績の保存 | `src/App.jsx` |
| アプリ名・アイコン（ホーム画面に追加したとき） | `public/manifest.webmanifest`、`public/icons/` |
| プライバシーポリシー | `public/privacy.html` |

### 問題の書き方（`src/data/questions.js`）

```js
// 選択問題：分野, 問題文, 選択肢, 正解の番号(0始まり), 根拠, 解説
M("sei","問題文",["選択肢1","選択肢2","選択肢3","選択肢4"],0,"第32条","解説"),
// ○×問題：分野, 問題文, 正しければ true, 根拠, 解説
T("sei","問題文",true,"第32条","解説"),
```

分野のキーは `kiso` `mono` `sha` `jin` `shi` `sei` `ki` `rin` `shin` `jitsu` です。新しい問題は各分野の末尾に追加してください（識別番号が分野内の並び順で付くため、途中に挿入すると苦手問題の記録がずれます）。

## 自分のパソコンで動かす

[Node.js](https://nodejs.org/)（20以上）をインストールしてから、このフォルダで次を実行します。

```bash
npm install      # 最初の1回だけ
npm run dev      # 開発用サーバーが起動。表示されたURLをブラウザで開く
```

ファイルを保存すると、ブラウザの表示がすぐに変わります。公開用のファイルを作るときは `npm run build` を実行します（`dist` フォルダに出力されます）。

## 公開

- **GitHub Pages**：`main` に push すると、GitHub Actions が自動でビルドして公開します（`.github/workflows/deploy.yml`）。リポジトリの Settings → Pages で、Source を「GitHub Actions」にしておく必要があります
- **Cloudflare Pages**：ビルドコマンドを `npm run build`、出力ディレクトリを `dist` に設定します

## 注意

「ビジネス著作権検定」は株式会社サーティファイの登録商標です。本アプリは同社とは関係のない非公式の学習アプリです。

公式の問題ではなく、出題範囲を参考にしたオリジナル問題です。内容は2026年10月時点の日本の著作権法にもとづく学習用の要約で、細かな要件や例外を省略している箇所があります。実際の判断が必要な場面では、条文・文化庁の資料や専門家に確認してください。
