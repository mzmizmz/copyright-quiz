# 著作権ドリル

日本の著作権法をクイズ形式で学べる学習アプリです。ブラウザだけで動き、インストールは不要です。

## 内容

- 全32問（選択式・○×問題）
- 5分野：著作物の基本／権利の中身／保護期間／自由に使える場面／侵害と罰則
- 1回10問。回答ごとに根拠条文と解説を表示
- 間違えた問題を「苦手な問題」として記録し、あとから復習できる
- 分野ごとの最高スコアを保存（ブラウザの localStorage を使用）
- キーボード操作：`1`〜`4` で回答、`Enter` で次へ

## 使い方

`index.html` をブラウザで開くだけで遊べます。GitHub Pages で公開している場合は、そのURLにアクセスしてください。

## 問題の追加

`index.html` 内の `Q` 配列に、次の形式で問題を追加します。

```js
{id:33, c:"kihon", q:"問題文", ch:["選択肢1","選択肢2","選択肢3","選択肢4"], a:0, ref:"第○条", e:"解説"}
```

- `c`：分野（`kihon` / `kenri` / `kikan` / `reigai` / `shingai`）
- `a`：正解の選択肢の番号（0始まり）
- ○×問題は `ch:TF, tf:true` とし、正しい場合 `a:0`、誤りの場合 `a:1`

## 注意

内容は2026年10月時点の日本の著作権法にもとづく学習用の要約です。細かな要件や例外を省略している箇所があります。実際の判断が必要な場面では、条文・文化庁の資料や専門家に確認してください。
